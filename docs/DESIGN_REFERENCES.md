# 吉利元亨｜網站設計參考與設計方向（討論草案）

> 2026-11-04 主理人提供兩個同行網站作參考。本文件只記錄可借鏡的設計原則；**不複製他人的品牌文字、Logo、照片或版面原始碼**。實際視覺風格及商品功能，等主理人確認後再實作。

## 參考網站 1：Tsay Tea

網址：https://tsaytea.com/

觀察：
- 導覽以 Home、Shop、Wholesale、Learn 連結品牌內容與購物流程。
- 首頁先談家族製茶歷史、茶農社群與真實人物，再引導進入 Shop。
- 商品頁提供品種、採收季節、產地、品飲描述等有助判斷的資訊。
- 學習方向：以人的故事打開品牌、用具體照片支持敘事、商品卡片清楚導向細節。

## 參考網站 2：Jesse's Teahouse

網址：https://jessesteahouse.com/en-us

觀察：
- 網站有多品類商品導覽（茶、茶具、訂閱等）和購物流程。
- About Us 以創辦人的經歷建立可信度，延伸到團隊及茶農合作夥伴。
- 同時經營茶文化內容和社群連結。
- 學習方向：讓主理人與茶文化成為品牌核心，未來再發展商品分類、會員與社群。

## 吉利元亨第一版：保持一頁式

建議區塊：
1. 主視覺：品牌名稱、照片、短句和清楚導覽。
2. 品牌敘事：主理人上山、製茶、選茶的理由。
3. 茶品展示：照片、經主理人核實的基本資料，可點開詳細頁。
4. 影像／文字檔案：茶山攝影與製茶紀錄的縮圖入口。
5. 合作與聯絡：Instagram https://www.instagram.com/kuei_puerhtea/ 。

實作原則：
- 現階段沿用 HTML / CSS / JavaScript，不為參考網站的購物功能先導入 Shopify 或複雜前端框架。
- 手機優先、清晰閱讀、相對路徑、圖片可延遲載入、減少動畫偏好。
- 正式茶品名稱、年份、產區、照片與品牌敘事由主理人確認，暫不創作虛構資料。
- 若未來需線上購物、庫存與付款，另外評估 Shopify、其他電商平台或串接方案。

## 待主理人選擇

兩個網站中最想借鏡的是：
- Tsay Tea 的家族／產地敘事與簡潔氛圍
- Jesse's Teahouse 的主理人形象、茶文化社群與商品分類
- 或兩者融合，但需要明確的視覺排序與內容權重

決定後，再製作首頁線框與視覺初版；避免只憑參考連結直接推定品牌美學。
